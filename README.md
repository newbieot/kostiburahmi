# Kost Ibu Rahmi — kost.posnew.com

Website statis untuk mempromosikan Kost Putri Muslimah Ibu Rahmi di Anduring, Padang.

## Deploy

Tidak membutuhkan build command atau npm. Upload seluruh isi folder ke root repository yang terhubung ke Cloudflare Pages.

## Halaman

- `/` — landing page utama
- `/flyer` — flyer rasio 4:5 untuk Facebook
- `/flyer-story` — flyer rasio 9:16 untuk Story

## Aset

Foto menggunakan WebP responsif dan mempertahankan rasio asli. Video telah dikompresi dan memakai `preload="none"` agar halaman tetap ringan.
